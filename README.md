## 📖 Sobre o Projeto

Este projeto consiste em uma **Prova de Conceito (PoC)** focada no *refactoring* e *rework* das interfaces do aplicativo oficial da universidade (**UCS**). 

O principal objetivo é aplicar os conceitos e diretrizes estudados na disciplina de **Interação Humano-Computador (IHC)** para melhorar a **usabilidade**, a **experiência do usuário (UX)** e o **design de interface (UI)** do aplicativo atual, tornando-o mais intuitivo, acessível e agradável para a comunidade acadêmica.

## 🎯 Objetivos e Diretrizes de IHC

- **Melhoria da Usabilidade:** Simplificação de fluxos e redução de cliques para acessar informações essenciais (como notas, quadro de horários e área financeira).
- **Heurísticas de Nielsen:** Avaliação e correção de problemas de usabilidade baseados nas 10 heurísticas de Jakob Nielsen (visibilidade do status, consistência, prevenção de erros, etc).
- **Acessibilidade:** Aplicação de contrastes adequados e tipografia legível para garantir que todos os perfis de estudantes consigam utilizar o app sem dificuldades.
- **Consistência Visual:** Padronização de componentes, cores e ícones, criando uma interface moderna e coesa.

## 🛠️ Tecnologias Utilizadas

Este protótipo de alta fidelidade/funcional foi desenvolvido utilizando tecnologias web web padrão (sem uso de frameworks complexos, focando na interface):

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização, layout e responsividade para simular a tela de um smartphone.
- **JavaScript (Vanilla):** Lógica de interface, navegação e interatividade.

## 🚀 Como Executar o Projeto

Como o projeto é construído em cima de tecnologias *client-side* puras, executá-lo é muito simples e não requer instalação de dependências ou servidores pesados.

1. **Clone o repositório:**
   ```bash
   git clone [URL_DO_SEU_REPOSITORIO]
   ```
2. **Acesse a pasta do projeto:**
   ```bash
   cd App_ucs
   ```
3. **Abra a aplicação:**
   Basta dar um duplo clique no arquivo `index.html` na raiz do projeto para abri-lo no seu navegador padrão.
   
   *(Recomendação: Para uma experiência de desenvolvimento contínua, utilize a extensão **Live Server** do VS Code).*

### Visualização em formato mobile

O protótipo foi pensado para simular o uso em smartphone. Para visualizar corretamente, use uma das opções abaixo:

- **No celular:** acesse o link publicado via GitHub Pages diretamente pelo navegador do aparelho.
- **No computador:** abra o projeto no navegador, pressione `F12` para abrir as ferramentas de desenvolvedor e clique no ícone de celular/tablet (**Toggle device toolbar**) no topo do DevTools. No Chrome, o atalho `Ctrl + Shift + M` só funciona quando o DevTools já está aberto e focado, então o botão é a opção mais confiável.

Caso esteja executando localmente com Live Server, também é possível acessar pelo celular usando o endereço IP da máquina na mesma rede Wi-Fi, seguido da porta exibida pelo Live Server.
